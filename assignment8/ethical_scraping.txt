# Ethical Web Scraping - Wikipedia robots.txt

## 1. Which sections of the website are restricted for crawling?

Wikipedia restricts several areas from general web crawlers. Some of the main restricted locations include:

* `/w/`
* `/api/`
* `/trap/`
* `/wiki/Special:`
* Other versions of the Special-page path

Wikipedia also restricts a number of administrative or maintenance-related pages, including some deletion discussions, 
copyright-problem pages, protected-title pages, spam-related pages, arbitration pages, and other special Wikipedia project areas.

There are a few exceptions that are explicitly allowed, including certain API and resource URLs.

## 2. Are there specific rules for certain user agents?

Yes. Wikipedia has specific rules for a number of web crawlers and bots.

Some user agents, such as `MJ12bot`, `HTTrack`, `wget`, `WebReaper`, and several others, are completely blocked from crawling the site with `Disallow: /`.

`SemrushBot` is given a `Crawl-delay` of 5 seconds so that it does not send requests too quickly.

Wikipedia also lists some of its own work bots, such as `IsraBot` and `Orthogaffe`, without any disallowed paths.

These rules show that Wikipedia treats different crawlers differently depending on their behavior and purpose.

## 3. Reflection

Websites use `robots.txt` to communicate which parts of a site automated crawlers should or should not access and, in some cases, how quickly they should make requests. 
Following these rules promotes ethical web scraping by reducing unnecessary server load, respecting website owners' preferences, and preventing scrapers from accessing areas that were not intended for automated collection.
